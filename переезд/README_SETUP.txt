ИНСТРУКЦИЯ ПО ПЕРЕЕЗДУ НА ARCH LINUX

1. Скопируйте всю папку проекта 'project_start' на ваш Linux-ноутбук.
2. Откройте терминал в папке 'project_start'.
3. Сделайте скрипт исполняемым:
   chmod +x переезд/setup_arch.sh
4. Запустите скрипт:
   ./переезд/setup_arch.sh

Скрипт автоматически:
- Обновит систему.
- Проверит и установит необходимые системные компоненты (Python, Node.js, Scrot).
- Создаст изолированное виртуальное окружение в папке 'agent_workspace'.
- Установит все необходимые Python-библиотеки.
- Установит ядро агента.

Примечание: Для работы скрипта необходимы права sudo (администратора).
