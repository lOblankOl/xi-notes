# Ξ-notes — два реальных фикса + важная проверка для остальных "не работающих" функций

## Два фикса в этом шаге

### 1. Список "Напоминания" в панели теперь закрыт по умолчанию
Мелкая, безопасная правка — раньше открывался сразу и занимал место.

### 2. РЕАЛЬНЫЙ баг: пункт списка/картинка вставлялись не на строку курсора
Раньше "куда вставить новый пункт" определялось только на уровне "какой
текстовый блок сейчас в фокусе" — а весь длинный абзац считался ОДНИМ
блоком целиком. Поэтому если курсор стоял в середине длинного абзаца, новый
пункт списка вставлялся ПОСЛЕ ВСЕГО абзаца целиком (что снаружи выглядело
как "появился в конце заметки"), а не сразу после конкретной строки, где
стоял курсор.

Исправлено: теперь отслеживается точная позиция курсора внутри блока
(через `TextFieldValue`/`selection`, а не просто строка текста), и при
вставке пункта/картинки абзац РЕЖЕТСЯ ровно по границе строки с курсором —
текст до курсора остаётся, новый пункт вставляется сразу после этой строки,
а остаток абзаца (если есть) продолжается уже после нового пункта.

## ⚠️ Про остальные функции, которые пользователь сообщил как "не работающие"

Я построчно перепроверил ВЕСЬ код (не только скобки — саму логику каждой
функции) на:
- диалог выбора повтора напоминания (не повторять/день/неделя/год);
- отображение времени напоминания в открытой заметке (не только в панели);
- восстановление последней открытой заметки при запуске;
- пункт "Цвет" в контекстном меню заметки и группы;
- отмену напоминания у пункта списка при отметке "выполнено".

**Весь этот код реально присутствует в проекте и корректно связан** (доведён
до конца, а не "написан, но никуда не подключён"). Это значит: то, что
пользователь не видит эти функции на телефоне — почти наверняка означает,
что именно ЭТОТ код не попал в APK, который он тестирует. Пожалуйста,
прогони следующую проверку и пришли результат — она даст точный ответ, без
дальнейших гаданий:

```bash
# Выполнить в корне репозитория ПОСЛЕ git pull (убедиться, что тянете свежее)
grep -n "Не повторять" app/src/main/java/com/xinotes/app/ui/NoteEditorScreen.kt
grep -n "KEY_LAST_NOTE_ID" app/src/main/java/com/xinotes/app/ui/NotesViewModel.kt
grep -n "\"Цвет\"" app/src/main/java/com/xinotes/app/ui/ReorderableNoteList.kt
```

- Если эти строки НАЙДЕНЫ в репозитории — значит код на месте, но до
  телефона дошла версия старее (стоит проверить: сборка идёт из последнего
  коммита? не установлен ли случайно старый скачанный APK из "Загрузок"?
  реально ли обновление прошло, или показало ошибку, которую пропустили?).
- Если эти строки НЕ найдены — значит правки из прошлого шага так и не
  попали в репозиторий (например, только применились локально, но не
  закоммичены и не запушены) — и нужно просто повторно применить содержимое
  прошлого архива поверх текущего состояния репозитория.

## Что делать с этим архивом

1. Заменить содержимое папки `xi-notes/` в репозитории этим архивом целиком
   (это гарантированно включает и прошлый набор функций, и два новых фикса
   из этого шага — так что даже если прошлый раз что-то не докатилось,
   сейчас всё будет полностью, одним разом).
2. Выполнить проверку выше ДО коммита, чтобы убедиться, что нужный код
   реально лёг в файлы.
3. Закоммитить, запушить, дождаться сборки, поставить как обновление.
4. Проверить: список напоминаний закрыт по умолчанию; пункт списка,
   вставленный в середине абзаца, появляется сразу после текущей строки, а
   не в конце заметки; и — самое главное — перепроверить все "не работающие"
   функции из прошлого раза заново.
